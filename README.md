# Athea Jean's Pink Portfolio

Open `index.html` in any browser—no installation or web server needed.

## Personalize it

- Replace `assets/profile-photo.svg` with your photo and update the image `src` in `index.html` if using a different filename.
- Search for `EDIT:` in `index.html` to update text, project details, and social links.
- Colors are defined at the top of `style.css`.

The profile image from the referenced ChatGPT chat was not available to retrieve, so this project includes a clearly labelled, original placeholder asset ready to replace.
